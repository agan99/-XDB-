## 1. Goal

在 Components/XDB 中建立动画媒体库 v0.1 的基础数据集合。

该数据集合只包含符合正式动画数据边界的 Bangumi 动画，并为后续 `Media Progress`、动画卡片和动画画廊提供基础数据。

本 Task 不实现进度能力、正式卡片或画廊功能。


## 2. Requirement

动画数据集合必须满足：

```text
作品大类 = 动画
AND
数据来源 = Bangumi
```

XDB 必须能够读取后续动画媒体库 v0.1 所需的以下正式字段：

- `作品大类`
- `数据来源`
- `name`
- `description`
- `中文名`
- `原名`
- `tags`
- `cover`
- `状态`
- `个人评分`
- `收藏`
- `Bangumi评分`
- `改编类型`
- `总集数`
- `开播日期`

本 Task 只读取现有媒体笔记中的正式数据，不新增用于展示的重复存储字段。

字段为空时，只要记录仍满足动画数据边界，不得仅因该字段为空而将记录排除出基础数据集合。


## 3. Scope

本 Task 只负责：

- 建立 Bangumi 动画的 XDB 基础数据集合；
- 应用正式动画数据边界；
- 确认后续 v0.1 所需基础字段能够被 XDB 读取；
- 提供足以验证数据集合和字段读取结果的最小可观察结果。


## 4. Relevant Specs

本 Task 需要读取：

- `媒体库展示数据约定.md`
  - 作为数据字段、动画数据边界和 XDB 数据职责的正式依据；
- `媒体卡片设计规范.md`
  - 仅用于确认后续动画卡片需要哪些基础字段；
- `媒体画廊设计规范.md`
  - 仅用于确认后续动画画廊筛选、搜索、排序所需的基础字段。

本 Task 不实现后两份规范中的卡片或画廊功能。


## 5. Architecture / Contract Boundary

- 现有媒体笔记是本 Task 的业务数据来源；
- 不修改现有媒体笔记的数据 Contract；
- 不新增第二套平行业务数据；
- 不修改现有媒体笔记中的业务数据；
- 不读取或修改正文中的 `已观看集数`；
- 不在本 Task 中实现动画进度的读取、标准化、计算或修改。


## 6. Out of Scope

本 Task 不实现：

- `Media Progress`；
- 正文 `已观看集数` 的读取或修改；
- 进度百分比等进度派生能力；
- 正式动画卡片及卡片交互；
- 动画画廊的筛选、搜索、排序、布局或加载；
- 游戏及其它媒体类型。


## 7. Acceptance Criteria

1. XDB 基础数据集合只包含同时满足以下条件的媒体记录：
   - `作品大类 = 动画`
   - `数据来源 = Bangumi`
2. Requirement 中列出的基础字段能够从真实媒体笔记中正确读取。
3. 满足动画数据边界的记录不会仅因某个可选字段为空而被错误排除。
4. 实现没有新增重复业务字段或第二套业务数据来源。
5. 实现没有修改现有媒体笔记中的业务数据。
6. 可以在 Components/XDB 中观察并确认当前动画数据集合及基础字段读取结果。


## 8. Verification / Human Acceptance

### 8.1 Agent Verification

检查：

- 数据集合条件与正式规范一致；
- Requirement 中列出的字段引用与正式字段名称一致；
- 没有引入重复存储字段；
- 没有实现本 Task Scope 之外的 Media Progress、卡片或画廊功能。

只报告实际完成的验证；当前环境无法执行的 Obsidian / Components 运行验证必须明确标记为未验证。


### 8.2 Human Acceptance

用户在 Obsidian / Components/XDB 中使用真实媒体笔记确认：

- 应进入数据集合的 Bangumi 动画正确进入；
- 不满足动画数据边界的记录没有进入；
- 基础字段读取结果与真实媒体笔记一致；
- 部分可选字段为空的合法动画仍存在于数据集合中。
