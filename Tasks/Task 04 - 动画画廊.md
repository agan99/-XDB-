## ⁠1. ⁠Goal

实现动画媒体库 v0.1 的动画画廊。

画廊负责动画集合的筛选、搜索、排序、卡片排列和渐进加载，并复用 Task 03 的动画卡片。

## ⁠2. ⁠Requirement

### ⁠2.1 ⁠筛选

状态筛选为单选：

```text
全部
在看
想看
已看
暂缓
```

规则：

* 点击状态只显示对应动画；
* 再次点击当前状态恢复「全部」；
* 「全部」只清除状态筛选；
* `收藏`、`集数未知` 为独立开关；
* 状态筛选和附加筛选之间使用 AND。

筛选按钮数量始终基于完整动画库统计，不随当前筛选或搜索变化。

### ⁠2.2 ⁠搜索

搜索范围：

```text
中文名
原名
tags
```

规则：

* 包含匹配；
* 英文字母忽略大小写；
* 忽略输入首尾空格；
* 多关键词以空格分隔；
* 多关键词之间使用 AND；
* 每个关键词可匹配三个搜索字段中的任意一个。

### ⁠2.3 ⁠排序

默认排序：

```text
状态优先级
→ 开播日期倒序
→ 标题正序
```

状态优先级：

```text
在看
→ 想看
→ 暂缓
→ 已看
```

提供四个可切换排序：

* 开播日期；
* 个人评分；
* Bangumi评分；
* 标题。

排序按钮采用：

```text
未选中
→ 默认方向
→ 反向
→ 恢复默认排序
```

同一时间只允许一个主动排序。

空值始终排在最后；主排序值相同时使用标题正序。

### ⁠2.4 ⁠卡片与布局

画廊必须复用 Task 03 动画卡片，不重新实现卡片内部展示和交互。

布局：

* 规则网格，不使用瀑布流；
* 卡片等高；
* 标准卡片尺寸 `330 × 430px`；
* 根据可用宽度自动调整列数；
* 最后一行从左向右排列；
* 不产生横向滚动条；
* 极窄窗口无法容纳 330px 卡片时允许整体等比缩小。

### ⁠2.5 ⁠渐进加载

不使用传统分页。

处理顺序：

```text
动画全集
→ 筛选
→ 搜索
→ 排序
→ 完整结果集
→ 分批渲染
```

第一版每批约 `24～30` 张。

接近结果底部时继续加载，直到当前完整结果集显示完毕。

筛选、搜索或排序发生变化时：

* 重新计算完整结果集；
* 重置已渲染批次；
* 从第一批重新显示；
* 回到卡片结果区域顶部。

卡片内部数据修改不默认导致整个画廊回到顶部；如果修改后不再满足当前筛选条件，只更新当前结果集并移除该卡片。

### ⁠2.6 ⁠空结果

筛选或搜索无结果时显示：

```text
没有找到匹配的动画
调整搜索或筛选条件试试
[清除条件]
```

「清除条件」清除搜索、状态及附加筛选，但保留当前排序。

动画库本身为空时显示：

```text
暂无动画
当前动画库没有可展示记录
```

画廊不提供新增动画入口。

## ⁠3. ⁠Scope / Contract Boundary

本 Task 只负责画廊级能力：

* 集合筛选；
* 搜索；
* 排序；
* 筛选数量；
* 卡片网格；
* 渐进加载；
* 空结果状态。

数据集合继续使用现有动画 XDB 数据边界。

单张卡片必须复用 Task 03，不在画廊中复制卡片字段、状态映射、Media Progress 或写回逻辑。

本 Task 不提前固定 `.xdb` / `*.xdb.js` 或具体 Gallery Renderer 技术方案，由 Plan Review 根据 Components/XDB 能力和对应 Skill 判断。

## ⁠4. ⁠Relevant Specs

* `媒体库展示数据约定.md`
* `媒体画廊设计规范.md`
* Task 03 动画卡片的正式 Contract / Approved Plan

## ⁠5. ⁠Out of Scope

本 Task 不实现：

* 新的动画卡片；
* 新的 Media Progress；
* 媒体数据新增或接入；
* 游戏及其它媒体画廊；
* 虚拟列表。

## ⁠6. ⁠Acceptance Criteria

1. 状态、收藏和集数未知筛选符合正式组合规则。
2. 筛选数量始终基于完整动画库。
3. 搜索范围和多关键词匹配行为符合 Requirement。
4. 默认排序及四种主动排序行为正确。
5. 空排序值始终排在最后，主排序相同时按标题正序。
6. 画廊复用 Task 03 动画卡片，没有重复实现卡片逻辑。
7. 网格能根据可用宽度响应式调整，并且不产生横向滚动条。
8. 筛选、搜索和排序作用于完整数据后再进行渐进渲染。
9. 条件变化会重置渐进加载；卡片内部修改不会无条件重置整个画廊。
10. 两种空结果状态及「清除条件」行为正确。
11. 没有实现其它媒体画廊或超出本 Task Scope 的能力。

## ⁠7. ⁠Verification / Human Acceptance

Agent Verification：

* 验证筛选、搜索和排序逻辑；
* 验证完整结果集与渐进加载顺序；
* 验证筛选数量不受当前条件影响；
* 验证 Task 03 卡片被复用；
* 验证没有引入其它媒体或重复卡片逻辑。

Human Acceptance：

* 在真实 Obsidian / Components 中检查画廊布局和响应式效果；
* 实际操作状态、收藏、集数未知筛选；
* 实际测试搜索和四种排序；
* 检查连续滚动加载及条件变化后的重置行为；
* 检查空结果与清除条件行为。
