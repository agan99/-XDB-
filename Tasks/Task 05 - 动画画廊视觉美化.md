# Task 05 - 动画画廊视觉美化

## Goal

参照用户提供的三张追番画廊截图，美化现有动画画廊与卡片的视觉样式。

## Requirement / Scope

- 使用截图中的分层标题区、柔和筛选控件、海报式卡片、封面角标、彩色标签和轻量进度展示作为视觉参考；背景和基础文字色跟随当前 Obsidian 主题。
- 画廊卡片最小宽度调整为 `210px`，保留根据容器宽度自动计算列数与封面高度的规则。
- 鼠标悬停或卡片内控件获得键盘焦点时，整张画廊卡片轻微上移；尊重系统的减少动画设置。
- 「追番画廊」标题使用更明确的加粗字重。
- 保留全部卡片和画廊业务逻辑、字段、数据来源、筛选、搜索、排序、进度、点击与写回行为。
- 不加入截图里当前库没有的额外按钮、统计、产地或其它数据。

## Acceptance Criteria

1. 亮色主题下，画廊和卡片在现有结构内呈现与参考截图相近的视觉层次，背景与当前 Obsidian 主题协调。
2. 画廊以 `210px` 为正常最小卡宽，仍按容器宽度自动换列且没有横向滚动。
3. 悬停上移和标题加粗生效；不改变卡片字段、交互或业务逻辑。
4. 插件语法、XDB 插件静态校验及现有测试通过。
5. 真实 Obsidian 中由用户检查亮色主题观感、窄窗口、hover、状态与进度操作。

## Target File

- `媒体库-动画卡片.xdb.js`
- `媒体画廊设计规范.md`（同步尺寸规则）
