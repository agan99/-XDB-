## 1. 技术路线

拟新建独立的 `媒体库-游戏卡片.xdb.js` 插件，注册稳定、带命名空间的游戏卡片 Field Type 与 Field Renderer。Renderer 从当前 `row.$item` 读取标准属性，在单卡容器中渲染封面区和正文区；功能字段不写入游戏笔记。

**视觉系统逐项对齐动画卡片**（这是本次修订的核心）：

| 项 | 对齐目标（动画卡片现值） | 游戏卡片做法 |
| --- | --- | --- |
| 卡片外壳 | `border-radius: 16px`、`1px solid var(--background-modifier-border)`、`background: var(--background-primary)`、`overflow: hidden`、纵向两行网格 | 同规格 |
| 宽度 | 画廊写入 `--agan-gallery-card-w`，卡片 `width: 100%` | `width: min(100%, 330px)`，窄容器自动收窄 |
| 封面 | 5:6 竖版（330×400），`object-fit: cover` | `aspect-ratio: 330 / 400`，同 `object-fit` |
| 四角徽章 | 左上 `改编类型`／右上 `状态`／左下 `开播年月`／右下 `★ 评分` | 左上 `游戏类型`／右上 `状态`／左下 `发行年月`／右下 `★ 评分` |
| 徽章规格 | 实色 `rgb(255 255 255 / 0.96)`、`1px solid rgb(0 0 0 / 0.1)`、`border-radius: 8px`、`box-shadow: 0 1px 2px rgb(0 0 0 / 0.22)`、`min-height: 1.375rem`、`padding: 2px 8px`、`font-size: 11px` | 同规格 |

**不随视觉一起继承**（动画卡片有、游戏卡片不要）：状态一键切换、收藏切换、集数增减、进度条与百分比、简介入口。游戏卡片保持只读。

受插件模型限制（两个 `*.xdb.js` 是各自独立加载的插件，无法互相 `require`），`TAG_COLOR_GROUPS` / `tagColorKey` 与 12 组色板必须在游戏插件中**再持有一份同构副本**。这是本次修订明确接受的代价，一致性靠 `Tests/Task 07 - 游戏卡片展示.test.cjs` 固定。

游戏卡片只负责单张卡片。真实 XDB 验收入口使用一张最小 table 显示该功能字段；游戏画廊另立任务。

## 2. 数据与展示

- 标题：`中文名 → 原名 → name → 未命名游戏`，最后一项仅为显示占位。
- 角标：`游戏类型`、`状态`；日期：`发行日期` 格式化为年月；评分：`个人评分`，其中 `0` 有效。
- 收藏：`收藏 = true` 时显示 ★，本任务不写回。
- 标签：过滤空项，保留原顺序，最多 5 个；每个标签写入 `dataset.color = tagColorKey(tag)`，由 12 组配色渲染；一个有效标签都没有时整行不创建。
- 信息行：`游玩平台` 与 `游玩分钟` 分别独立降级；两者皆无值时隐藏。
- 时长：只接受非负整数分钟，拆分为小时与余分钟；`150 → 2小时30分`、`60 → 1小时`、`30 → 30分钟`、`0 → 0分钟`。空值或非法值不显示时长。
- 不渲染百分比、进度条、简介或简介入口。
- DOM 保持与动画卡片同构：`Root` → `CoverArea`( `CoverFrame` + `CoverTop` + `CoverBottom` ) + `Body`( `Title` + `Tags` + `Info` )。角标全部使用同一个徽章 class；`CoverTop` / `CoverBottom` 绝对定位、`pointer-events: none`，避免遮挡封面。
- 状态角标文案先剥掉前置 emoji（`^[\p{Extended_Pictographic}...]`），再按四态取标识色；剥不掉时按原值显示，不猜测。
- 卡片保持只读：状态角标不可点击、无收藏切换、无集数操作、封面无点击。

## 3. XDB 接入

当前 `媒体库.xdb` 的全局 filter 为动画与 Bangumi；即使加入游戏卡片字段，游戏记录也不会进入该库。用户选择单独建立 `*.xdb.js` 游戏卡片插件，因此配套新建独立的 `游戏媒体库.xdb`：`source = file`，全局 filter 为 `作品大类 = 游戏 AND 数据来源 = Bangumi`，保留原库与动画数据边界。该库只提供最小 table 单卡验收入口，不新增游戏画廊。

`媒体库-游戏卡片.xdb.js` 注册无存储值的游戏卡片 Field Type 与 Field Renderer；`游戏媒体库.xdb` 定义该功能字段，并在 table 的 `visibleFields` 中展示它。插件与数据库配置各自承担自己的职责。
